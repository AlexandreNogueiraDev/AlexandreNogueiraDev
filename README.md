### ⭐ Projeto em Destaque — Trabalho de Conclusão de Curso

#### 🎓 [GuiaUni — Plataforma de Orientação Vocacional e Escolha de Cursos](https://github.com/HiveTech-TCC/GuiaUni)

**Projeto desenvolvido em equipe pela HiveTech como Trabalho de Conclusão de Curso do Técnico em Desenvolvimento de Sistemas da ETEC de Guaianazes.**

O GuiaUni é uma plataforma web criada para auxiliar jovens na escolha de uma carreira profissional e de um curso superior. O sistema reúne informações sobre cursos e instituições de ensino e oferece recursos de orientação vocacional para apoiar decisões acadêmicas mais conscientes.

**Principais funcionalidades:**
- Teste vocacional interativo com recomendações alinhadas aos interesses do usuário.
- Busca de cursos e instituições com filtros.
- Organização de cursos por áreas do conhecimento.
- Perfil de usuário, favoritos e histórico de buscas.
- Áreas administrativa e institucional para gerenciamento de informações.

**Tecnologias utilizadas:** Laravel, PHP, MySQL, HTML, CSS e JavaScript.

**Minha participação:** desenvolvimento colaborativo de uma aplicação web, trabalhando com funcionalidades de sistema, banco de dados e organização do projeto em equipe.

🔗 **[Acessar repositório do GuiaUni](https://github.com/HiveTech-TCC/GuiaUni)**
